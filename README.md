# Evaluaciones Suconel

Evaluaciones de selección múltiple para la formación de asesores de Suconel: 12 evaluaciones de 15 preguntas cada una, pensadas para proyectar en pantalla grande.

- Electrónica · Equipos de medida · Desarrollo, robótica y 3D · Automatización y control
- CCTV y redes · Casos de visita: medida · Energía solar y baterías · Soldadura y herramientas
- Fuentes, protección y motores · Marcas y posicionamiento · Casos: automatización, CCTV y solar · Seguridad eléctrica y normativa

## Uso

Abre la página, elige una evaluación (o usa las teclas 1-9) y responde con 1-4 o A-D.
P muestra una pista, R revela la respuesta, ← → navegan y F activa la pantalla completa.

Puntaje: 10 puntos por acierto, 5 si se usó la pista.

## Estado

Esta versión publicada en GitHub Pages funciona en modo práctica: los puntajes no se guardan.
El login con usuario y contraseña y la tabla de resultados se conectarán a un backend (Firebase) en una siguiente versión.

Todo el sitio es un único `index.html` sin dependencias de compilación.
